# Security policy

How to report a security problem in this CarLink build (Changan CS75 Plus 2023).

## Supported versions

Only the latest release on [GitHub Releases](https://github.com/0nezar0/carlink-releases/releases/latest)
gets fixes. The in-app updater offers new releases to installed copies.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately by email to
[alhazmi.n.car@gmail.com](mailto:alhazmi.n.car@gmail.com).

Include the CarLink version, the device and Android version, what an attacker can do and the
steps to reproduce. Do not include Wi-Fi or hotspot passwords or other personal data.
